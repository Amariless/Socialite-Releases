# Socialite — descargas

Instaladores de **Socialite**: todas tus redes sociales, correo y mensajería en una sola app de escritorio, con perfiles de sesiones aisladas.

Descarga la última versión desde [Releases](../../releases/latest):

| Sistema | Archivo |
| --- | --- |
| Windows | `Socialite-Setup-<versión>.exe` |
| Linux (cualquiera) | `Socialite-<versión>-linux-x86_64.AppImage` |
| Arch / CachyOS / Manjaro | `Socialite-<versión>-linux-x64.pacman` → `sudo pacman -U <archivo>` |
| Debian / Ubuntu | `Socialite-<versión>-linux-amd64.deb` |

La app se actualiza sola desde este repositorio (Ajustes → Acerca de → Buscar actualizaciones).

Este repositorio solo contiene los instaladores publicados; el código fuente es privado.
